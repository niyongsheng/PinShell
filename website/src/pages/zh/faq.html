FAQ

常见问题

窗口怎么移动和缩放、数据去了哪里——关于 PinShell 的常见疑问都在这里。

PinShell 免费吗？

免费且开源，许可为 Apache 2.0。没有账号、订阅或内购；官网模板库中的第一方模板也全部免费，并可独立更新。

使用数据会上传吗？

不会。PinShell 没有账号体系和遥测，页面在本机以 file:// 运行，MCP 与 CLI 通过本机 control.sock 通信。只有主动安装模板时才会从官网下载模板文件；股票看板、AI 电台等模板会自行请求公开数据接口。

怎样制作自己的模板？

不用写代码：在控制台 → MCP 页复制配置，粘贴到豆包、千问、DeepSeek Harness、WorkBuddy 等支持 MCP 的客户端，让 AI 自动完成配置。之后在会话里描述想要的界面或改动，AI 会创建、修改和管理模板，窗口即时预览。

如何贡献模板到官网？

在 website/templates/<id>/ 下添加 template.json 与 <id>.html，按模板贡献规范完成清单、多语言与设计令牌要求，跑通本地校验后向 niyongsheng/PinShell 提交 PR（标题 feat(template): add <id>）。合并后会自动发布到官网和 App 在线模板库。

如何移动或缩放悬浮窗？

桌面悬浮模式下，按住 ⌘ 拖动窗口任意位置即可移动；拖动窗口右下角的调整手柄可以改变大小。也可以在菜单栏 PinShell 图标 →「窗口位置」中把窗口贴到屏幕四角。顶栏弹出模式下，窗口位置始终跟随菜单栏图标，不能自由拖动。

「桌面悬浮」和「顶栏弹出」有什么区别？

桌面悬浮把窗口常驻在桌面之上，可自由移动、缩放与穿透；顶栏弹出把模板挂在菜单栏图标下方，点击图标展开、点击外部收起，位置固定。两种方式都可以从菜单栏 PinShell 图标 →「显示方式」随时切换。

macOS 提示「无法验证开发者」或「已损坏，无法打开」？

安装包使用 ad-hoc 签名，尚未完成公证。请前往「系统设置 → 隐私与安全性」点击「仍要打开」，或先执行 xattr -dr com.apple.quarantine ~/Downloads/PinShell-*.pkg 再安装。
