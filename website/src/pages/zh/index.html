{{HERO_PANELS}}

Overlay

桌面之上，多一层。

常驻置顶、跨 Space、鼠标穿透。PinShell 只负责把一块透明的 HTML 画布放到桌面上，内容完全由你决定。

01

常驻桌面

窗口浮在所有 Space 之上，可调透明度、圆角与点击穿透；需要时出现，不抢焦点。

02

HTML 即界面

CSS、Canvas、SVG、动画、音视频。任何浏览器能做的，窗口里都能做，不需要原生控件。

03

随时改写

Agent 可以直接写入、更新、热重载页面。界面跟着对话走，而不是提前打包。

MCP native

Agent 接管，
能说也会道。

PinShell 的 MCP server 与 CLI 共用一条控制 socket。页面按钮、表单和事件会回到 Agent，形成真正的双向对话。

pinshell_emit pinshell_await_event pinshell_state pinshell_template_show 
// Claude Code · .mcp.json
{
  "mcpServers": {
    "pinshell": {
      "command": "/Applications/PinShell.app/Contents/MacOS/PinShell",
      "args": ["mcp"]
    }
  }
}
