Overlay

One more layer, above the desktop.

Always on top, across Spaces, click-through when you need it. PinShell only places a transparent HTML canvas on the desktop; the content is yours.

01

Always there

Floats above every Space, with adjustable opacity, radius, and click-through. It appears when needed and never steals focus.

02

HTML is the interface

CSS, Canvas, SVG, animation, audio, and video. Anything the browser can do, the window can do — no native controls required.

03

Rewritten live

The agent can write, update, and hot-reload the page. The interface follows the conversation instead of being packaged in advance.

MCP native

Agent takes over.
Eloquent, too.

PinShell's MCP server and CLI share one control socket. Buttons, forms, and events travel back to the agent, making the window a real two-way conversation.

pinshell_emit pinshell_await_event pinshell_state pinshell_template_show

{
  "mcpServers": {

      "args": ["mcp"]
    }
  }
